# 复杂量化计算与逻辑推演

## 依赖的底层工具 (Required Tools)
- `calculate_with_python`: (必须从 MCP Server 获取) 隔离的代码沙箱。

## 标准作业流程 (SOP)
1. **收集与清洗**：获取所有需要参与计算的原始数据段落。
2. **明确计算目标**：用精确的自然语言写下你需要得出的最终结果（例如"计算 2023 年和 2024 年毛利率的同比增长率"）。
3. **下发任务**：调用 `calculate_with_python`，将原始数据和计算目标传入。
4. **结果集成**：等待沙箱返回 `[✅ Calculation Success]` 及其数值结果。如果沙箱报错，重新调整你的计算目标并重试。
5. **交付**：将沙箱返回的确切数值写入报告中。

## 绝对红线 (What NOT to do)
- 🚫 **绝对禁止**你自己（大语言模型）进行任何手动的加减乘除、乘方、开根号或单位换算。
- 🚫 **绝对禁止**在没有得到沙箱明确返回值的情况下，输出猜测的计算结果。
