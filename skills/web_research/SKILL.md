# 高级网页搜索与深度阅读

## 依赖的底层工具 (Required Tools)
- `tavily_search`: (MCP 工具) 用于广度搜索，获取网页标题、URL 和摘要。
- `fetch_webpage`: (MCP 工具) 用于深度抓取特定网页的全文 Markdown 文本。

## 标准作业流程 (SOP)
1. **广度侦察 (Broad Search)**：
   - 面对研究任务，首先调用 `tavily_search`。
   - 搜索词必须精简、准确。如果遇到专有名词、特定网站（使用 site: 操作符），请精准构造。
   - 严禁使用过长的自然语言句子作为搜索词。
2. **评估摘要 (Assess Snippets)**：
   - 仔细阅读 `tavily_search` 返回的 snippets（摘要）。
   - 如果摘要中的信息已经足够回答问题，**立刻停止搜索**，整合信息并输出。
3. **针对性精读 (Targeted Deep Reading)**：
   - 如果摘要信息太浅（例如需要具体的财务数据表格、深入的背景故事），挑选 1 到 2 个最具权威性的 URL。
   - 调用 `fetch_webpage` 工具抓取这 1-2 个网页的完整内容。
   - **绝对红线**：严禁无脑遍历抓取所有搜索到的 URL！
4. **PDF 熔断机制 (CRITICAL)**：
   - 如果你发现包含关键信息的 URL 是一个 `.pdf` 文件，或者是一个长达数十页的巨型文档。
   - **绝对禁止**使用 `fetch_webpage` 抓取它（会导致上下文崩溃）。
   - 此时，你应该意识到当前任务超出了普通网页搜索的范畴，需要依靠长文档挖掘技能（如果未分配，请向主管报告你需要长文档处理能力）。
