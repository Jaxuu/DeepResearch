# 算法与空间逻辑推理

## 依赖的底层工具 (Required Tools)
- `execute_python_code`: **(核心)** 所有算法必须用代码严格推演，禁止心算。

## 工具使用要点
- 代码必须 `print()` 出**带完整上下文的结果**（例如 `print(f"Answer: {result}")`），不要只打印孤立的数字，否则会被下游提取器丢弃。
- 代码最外层包 `try/except` 并 `print` 出错误信息，方便自我纠错。
- 如果一次执行报错，**修改代码重试**，不要换工具。

## 算法选择决策表 (CRITICAL)
先判断题目问什么，再选算法。**不要用错算法**。

| 题目特征 | 算法 |
|---|---|
| "最短路径 / 最少步数 / 能否到达" | BFS |
| "走遍所有 X 并回到起点 / 不重复经过" | DFS + 回溯（哈密顿回路），用度数 < 2 剪枝 |
| "第 K 回合落在哪个格子 / 每回合移动 N 格" | BFS + 状态机，state = (pos, last_direction, turn) |
| "最少几个塔/点覆盖所有目标" | 贪心区间覆盖 |
| "图上的连通性 / 连通分量" | 并查集 或 BFS |

## 回合制模拟的关键坑 (CRITICAL)
- **"回合"≠"步数"**：若每回合移动 N 格，第 K 回合的绝对位置是路径上的第 K×N 步。
- **方向选择**：如果题目**未指定方向优先顺序**，禁止自行规定 `[up, down, left, right]`。用 BFS/DFS 在状态空间 `(row, col, last_dir, turn)` 上搜索。若问"第 K 回合落在哪"，所有合法路径的落点应唯一；若枚举出多个，说明约束理解有误，重新读题。
- **"不能后退"**：通常指"不能走上一步的反方向"，不是"不能回到已访问的格子"。仔细区分题目用词。

## 输出交付
- 结论必须用**完整句子**或**题目要求的精确格式**输出。
- 如果是 Yes/No 题，直接输出 `Yes.` 或 `No.`。
- 如果是数值题，输出带上下文的完整句子（如 `The minimum number of towers is 3.`）。

## 绝对红线
- 🚫 禁止心算任何网格坐标、路径长度、连通性判断——必须写代码。
- 🚫 禁止硬编码网格范围（如 `range(1, 30)`），必须用 `max_row` / `max_column` 或从数据动态推导。
- 🚫 禁止在没有明确指令的情况下自行添加题目没有的约束（如"必须先向上"、"必须走偶数步"）。
