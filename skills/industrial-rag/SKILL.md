# 工业设备智能运维知识检索

## 依赖的底层工具 (Required Tools)
- `search_equipment_knowledge`: 用于查询内部知识库并获取结构化回答。

## 核心参数构造规则 (CRITICAL)
当你调用 `search_equipment_knowledge` 工具时，输入的 `query` 必须满足以下条件，否则知识库的实体识别节点会直接拦截：
1. **必须包含确切的设备全称或型号**：不能只用"离心泵"这种泛指词，如果用户没有提供具体型号，请原样传入包含故障上下文的自然语言整句（例如："设备报 ERR-OVERHEAT-09 故障应该如何排查？"），让知识库自己去理解。
2. **禁止使用纯关键词堆砌**：不要传入类似 `ERR-OVERHEAT-09 离心泵 车间内` 这种生硬的词组，请始终将其包装成一句完整的提问。

## 标准作业流程 (SOP)
1. **意图识别**：确认用户的需求属于工业设备维护或操作规范领域。
2. **提取检索词**：直接将用户的核心问题转化为精简、准确的查询字符串（Query）。无需包含"请告诉我"等废话。
3. **调用工具**：将查询字符串传入 `search_equipment_knowledge` 工具。
4. **解析 JSON 响应**：
   - 工具会返回一个包含 `rag_direct_answer` (系统直接生成的回答) 和 `reference_documents` (参考原文片段) 的 JSON 字符串。
   - 优先阅读 `rag_direct_answer` 了解核心结论。
5. **整合输出**：在最终报告中，根据 `rag_direct_answer` 给出你的回答，并严谨地引用 `reference_documents` 中的内容作为事实依据。

## 绝对红线 (What NOT to do)
- 🚫 **绝对禁止**在没有调用该知识库的情况下，凭借通用大模型的预训练记忆去瞎编设备的故障代码或维修步骤，这会导致严重的安全生产事故！
