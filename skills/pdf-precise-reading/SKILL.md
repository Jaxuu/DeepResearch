# 超长 PDF 精确阅读

## 依赖的底层工具 (Required Tools)
- `read_pdf_by_page`: 精准读取 PDF 的特定页码。

## 标准作业流程 (SOP)
1. **探测目录**：如果你不知道答案在哪一页，先调用 `read_pdf_by_page` 读取前 5 页（通常包含 Table of Contents 目录）。
2. **定位页码**：从目录中找到目标章节所在的页码。
3. **精准降落**：再次调用 `read_pdf_by_page`，传入目标章节所在的页码区间（例如 45 到 48 页），直接读取目标文本并回答用户问题。
4. **警惕幻觉**：如果没在指定页码找到答案，扩大阅读范围。绝不允许自己编造财报数据。
