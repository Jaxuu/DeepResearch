# Python 代码沙盒与复杂量化计算

## 依赖的底层工具 (Required Tools)
- `execute_python_code`: (必须从 MCP Server 获取) 用于在本地沙盒环境中执行一段完整的 Python 代码，并捕获返回的标准输出 (stdout) 和错误信息 (stderr)。

## 标准作业流程 (SOP)
1. **明确任务与收集信息**：若是文件解析，定位文件在当前工作空间中的绝对路径；若是复杂数学计算与逻辑推演，先收集参与计算的原始数据段落，并明确你需要得出的最终结果（如"计算2023年毛利率"）。
2. **编写执行脚本**：编写独立、功能完整的 Python 代码。根据任务类型自主引入恰当的库：
   - 处理 Excel 的单元格颜色、合并或公式 -> 必须使用 `openpyxl`
   - 处理 Word 的段落与特定排版 -> 必须使用 `python-docx`
   - 处理 PPT 的幻灯片页数与内容 -> 必须使用 `python-pptx`
   - 处理大规模结构化计算、复杂财务数据、概率统计 -> 使用 `pandas` 或 `numpy`
   - 处理基础复杂公式、乘方开根号 -> 使用内置 `math`
3. **暴露输出结果**：代码的最后，必须使用 `print()` 语句将计算结果或提取到的信息打印出来。沙盒只会捕获标准输出，无 `print` 则无结果。
4. **调用执行与自我纠错 (Self-Correction)**：调用 `execute_python_code` 工具执行代码。仔细检查返回结果，如果返回了 `stderr` 报错信息（如缺少依赖、索引越界、文件未找到），你必须分析报错原因，**重新调整代码或计算目标并再次调用工具**，直至获得正确结果。
5. **最终交付**：将沙箱返回的确切数值或提取内容转化为自然语言写入最终报告中。

## 绝对红线 (What NOT to do)
- 🚫 **绝对禁止**你自己（大语言模型）进行任何手动的加减乘除、乘方、开根号或单位换算，所有计算必须交由代码执行。
- 🚫 **绝对禁止**在没有得到沙箱明确返回值的情况下，输出猜测或未经验证的计算结果。
- 🚫 **绝对禁止**通过基础文本读取机制强行解析 `.xlsx`、`.pptx` 等富格式文件，这会导致关键多模态信息彻底丢失。
- 🚫 **绝对禁止**试图通过代码去加载、读取并往 MCP 工具里传递巨大的文件字节流（Bytes）。代码只需直接通过绝对路径读取本地文件即可。
- 🚫 **绝对禁止**在代码中使用 `input()` 或绘制阻塞式 GUI（如 `plt.show()`），沙盒环境是无人值守和非交互式的。
