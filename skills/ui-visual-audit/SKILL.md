# 网页前端视觉与布局审计

## 依赖的底层工具 (Required Tools)
- `analyze_webpage_visual_layout`: (必须从 MCP Server 获取) 驱动真实浏览器并使用视觉大模型的审查工具。

## 标准作业流程 (SOP)
1. **识别视觉问题**：当用户的查询包含"什么颜色"、"在左边还是右边"、"是否缩进"、"样式如何"时，说明单纯的 HTML 代码无法回答。
2. **定义审查目标**：明确指出需要观察的网页 URL 和具体的视觉问题。
3. **下发审查**：调用 `analyze_webpage_visual_layout`，等待视觉模型的反馈。
4. **输出结论**：将视觉审查的结果整合进最终回答。

## 绝对红线 (What NOT to do)
- 🚫 **绝对禁止**通过获取网页的源代码（HTML/CSS文本）来猜测元素的最终渲染位置或颜色。
